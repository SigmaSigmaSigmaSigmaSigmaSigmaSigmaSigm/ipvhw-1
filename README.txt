Лабораторна робота №1. Верстка та CSS
Виконав: Давиденко

Для запуску відкрити index.html у браузері.

index.html — сторінка Teachinder і два попапи.
styles.css — стилі та мобільна версія для екранів менше 768 px.
script.js — відкриття та закриття попапів.
answers.txt — відповіді на контрольні запитання.

Використано Grid для карток, Flexbox для шапки та меню,
float для фотографії викладача у попапі.

Пошук, фільтри, таблиця, обране та форма додавання — це макет,
без обробки даних. Для цієї роботи потрібна тільки верстка.
Попапи відкриваються кнопкою Add teacher та натисканням на викладача.
Закрити їх можна хрестиком або клавішею Escape.

Макет і фотографії взято з матеріалів лабораторної.
Шрифт Source Sans Pro: ліцензія в assets/OFL.txt.
